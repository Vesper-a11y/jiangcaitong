# 插件目录

这里每个子目录是一个插件，文件名就是版本号：`plugins/<id>/1.0.0.js`。
写一段 `.js` 交给这个仓库，维护者看过合并进 `main` 就会自动上架，不用改 App 源码、不用重新打包。

## 从模板开始

🔴 **[`_template.js`](_template.js) 就是模板** —— 复制它，改几个字就是一个插件。
里面有四种写法（画卡片 / 整页界面 / 改外观 / 调宿主）、文件头三行注释怎么填，
以及 `plugin.host` 的全部 API 速查表。打开 [`plugins/` 目录](.) 时这份说明会自动显示在文件列表下面。

最小能上架的样子：

```js
/* @name 空教室
 * @tag 教室
 * @desc 今天哪几间空着 */
plugin({
  name: '空教室', tag: '教室',
  stats() { return [['空着', '3 间']]; }
});
```

## 怎么交

1. 在 App 里点「插件市场 → 我也做一个」，或打开
   [GitHub 新建文件页](https://github.com/Vesper-a11y/jiangcaitong/new/main/plugins)。
   新建页是空白的，**先把模板复制过去**再改。
2. 路径写 `plugins/<你的 id>/1.0.0.js`，贴进代码，提交后 GitHub 自动开 PR。
3. 维护者看过代码、合并进 `main`，**就上架了**。
   [`index.json`](index.json) 不用写——合并后由 `tools/sync_index.py` 自动算出字符数和 sha256 补上。
4. 改了内容要换新版本号（新文件名），旧版可以留着；删掉文件即下架。

文件头 `@name / @tag / @desc` 决定市场卡片显示什么（标题 / 角标 / 简介），
不写就退回用目录名、标签写「插件」。完整规矩见仓库根目录的
[CONTRIBUTING.md](../CONTRIBUTING.md)。

⚠️ 插件权限是放开的（能调宿主路由、页面、底部导航、设置和原生能力），
所以每个 PR 都会先人工看一遍代码再合并。目前市场最多显示 8 个插件。
