# 酱菜通

一款面向江西财经大学同学的安卓小工具，把平时要来回切好几个 App 才能看到的信息，集中到一个界面里。

> 本项目是个人自用的非官方作品，与学校没有任何官方授权或关联。

## 它能做什么

- **教务**：课表、成绩、考试安排、作业，按学期查看，支持主题配色和上课时间自定义。
- **学习通**：作业、签到和积分任务，临近截止的事项会提醒你，不用反复进 App 翻。
- **住理生活**：洗澡热水的余额与账单，扫码添加设备后可查看每月支出。
- **智慧江财**：宿舍电费余额、电费与网费记录、网费到期推算。**只做查询展示，不提供任何充值、付款功能。**
- **桌面小组件**：把课表和待办放到桌面，抬眼就能看到今天做什么。

数据全部来自你自己在学校各系统里已能访问到的页面，只做读取和展示，不会代你提交选课、报名或任何修改。

## 下载与安装

到本仓库的 [Releases](../../releases) 页面下载最新的 `jiangcaitong-x.x.x.apk`，传到手机上安装即可。

- 安卓 8.0 及以上。
- 首次安装需要在系统设置里允许「安装未知来源应用」。
- App 内不自动付款、不扣费；涉及微信小程序的部分只会帮你打开官方小程序，付款请在你自己确认后完成。

## 更新

App 启动时会静默检查一次新版本。检测到更新后，「我的 → 关于」里的版本号旁会亮一个小点，点进去可以看到更新说明和下载入口。

你也可以在「我的 → 关于」里手动重新检查。更新清单和安装包都放在本仓库的 Releases 里。
