# 酱菜通

一款面向酱菜同学的安卓小工具，把平时要来回切好几个 App 才能看到的信息，集中到一个界面里。

> 本项目是个人自用的非官方作品，与学校没有任何官方授权或关联。

## 它能做什么

- **教务**：课表、成绩、考试安排、作业，按学期查看，支持主题配色和上课时间自定义。
- **学习通**：作业、签到和积分任务，临近截止的事项会提醒你，不用反复进 App 翻。
- **住理生活**：洗澡热水的余额与账单，扫码添加设备后可查看每月支出。
- **智慧江财**：宿舍电费余额、电费与网费记录、网费到期推算。**只做查询展示，不提供任何充值、付款功能。**
- **桌面小组件**：把课表和待办放到桌面，抬眼就能看到今天做什么。

数据全部来自你自己在学校各系统里已能访问到的页面，只做读取和展示，不会代你提交选课、报名或任何修改。

## 下载与安装

到本仓库的 [Releases](../../releases) 页面下载最新的 `jiangcaitong-x.x.x.apk`，传到手机上安装即可。

- 安卓 8.0 及以上。
- 首次安装需要在系统设置里允许「安装未知来源应用」。
- App 内不自动付款、不扣费；涉及微信小程序的部分只会帮你打开官方小程序，付款请在你自己确认后完成。

## 更新

App 启动时会静默检查一次新版本。检测到更新后，「我的 → 关于」里的版本号旁会亮一个小点，点进去可以看到更新说明和下载入口。

你也可以在「我的 → 关于」里手动重新检查。更新清单和安装包都放在本仓库的 Releases 里。

## 隐私说明

- 登录信息只加密保存在你这台手机上，不经过任何第三方服务器。
- 本项目不包含任何账号收集、上报或统计功能。
- 清除本机缓存后需要重新登录。
- **AI 助手（可选功能）**：只有当你主动开启并使用它时，你输入的对话内容和它查询到的结果
  （如课表、电费）才会发送给你自己填写的 AI 服务商。服务密钥只保存在你这台手机，
  不会随请求回传给本项目。不使用 AI 助手时，不会产生任何第三方请求。

## 做插件

想加一张卡、一个整页，或者换个配色，都不用改 App 源码、不用重新打包。写一段 `.js` 交给仓库就行：

- **模板**：[`plugins/_template.js`](plugins/_template.js) —— 四种写法和 `plugin.host` 全量 API 速查，复制过去改几个字就能用；[`plugins/` 目录](plugins/) 下也有说明
- 放进 `plugins/<id>/<版本>.js`，到 [GitHub 新建文件页](https://github.com/Vesper-a11y/jiangcaitong/new/main/plugins) 提交 PR
- 合并后自动上架，[清单](plugins/index.json) 不用你写；完整规矩见 [CONTRIBUTING.md](CONTRIBUTING.md)

插件权限是放开的，所以每个 PR 维护者都会先看一遍代码再合并。
